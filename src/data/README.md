# Données mock

Déposez ici les fichiers JSON/TS servant de base aux écrans statiques (voitures, concessionnaires, services...).

- `vehicles.ts` : annonces, specs, références d’images.
- `dealers.ts` : infos concessionnaires (nom, ville, contacts, WhatsApp).
- `services.ts` : les 7 piliers + partenaires.

Exporter en TypeScript (`export const vehicles = [...]`) pour profiter du typage dans les composants.
